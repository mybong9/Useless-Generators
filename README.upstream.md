T档只接受有用物质，三个K档还可以烧岩浆。其余九级无用物质与有用物质可用于所有非T档；有用物质可用于全部十档。

九种无用块各由9个对应的 `useless_mod:useless_ingot_tier_N` 合成，可拆回9锭。无用物质在万象炉中以对应无用块、水、煤炭、火药制备，每批产出1B；1至9级分别消耗对应无用块1/2/4/8/16/32/64/128/256个，煤炭数量为块数×4，火药数量为块数，水量为块数×1000mB。等级越高，原料等级和数量均提高。

有用物质仅由已成型的万象炉多方块制作：1024有用锭、2,100,000,000mB岩浆、1024煤炭块、九种无用块各1024个，每批暂定产出1B，处理1200tick并消耗100M FE。配方位于 `data/useless_generators/recipes/fuel/useful_fuel.json`，可由数据包覆盖。

任意已启用的能量面都可直接接 ME 线缆向网络供电，无需能量接收器，不占频道，空闲耗电为零。使用 AE2 配置的 FE→AE 换算比例，默认 2 FE = 1 AE。AE按实际已连接面的能量模式供电或充电，关闭的面不暴露AE节点。双向模式允许 FE 输入/输出，AE 优先输出以避免同一网络循环充放电。AE 与 FE 共用储能和对应输入/输出预算。AE 网络满电时拒收的能量留在设备中，不会虚空消耗。接口保存节点数据、跟随区块加载与卸载创建/销毁，放置时记录玩家。设备正面朝向放置者，背面保留AE接口外观，实际连接支持任意已启用能量面。

内部使用 Core 的 `LongEnergyHandler` 接口。Forge Energy 的单次调用只能使用 `int`，高档设备主动输出时以多个 int 数据包传输；FE 查询显示值上限为 2,147,483,647，真实储量仍为 long。实际输电速度受相邻设备、线缆接收能力限制；仅支持每 tick 一次 int 抽取的线缆无法传输最高档全部产量。主动发送遇到部分接收就切换下一面，避免低吞吐设备造成长循环。

1K 配方：`IRI / RFR / IRI`（I 铁锭、R 红石、F 熔炉）。后续每级：`RPR / PCP / RPR`（R 红石块、P 上一级发电机；C 为 16K/256K 档金锭，1M/16M/256M 档钻石，1G 及以上下界之星）。配方可由数据包覆盖。

## 1.2.1 界面与六面配置

界面采用 AE 面板风格，参考 Applied Generators 1.21.1 的奇点发电机界面结构。储罐支持真实流体贴图、容量提示、已消耗燃料剩余能量，储能条悬停显示完整 long 数值。玩家背包可正常移动物品，未增加物品燃料槽。

六个世界方向分别配置流体与能量：关闭、输入、输出、双向。默认流体输入、能量输出，旧存档自动采用此默认值。配置写入方块 NBT，修改时刷新外部能力连接；被缓存的旧能力对象也按最新权限检查。流体输出面可主动向相邻接收器输送最多1000mB/t，六面分别独立控制；能量输入和输出分别共享整机每tick预算。

手持满桶/空桶右键方块会优先执行该面的流体交互；燃料不支持、空间不足或面权限不允许时保持物品不变，不会向旁边泼出燃料。普通右键打开GUI。GUI中拿起流体容器点击储罐，直接访问内部储罐，不受管道面配置影响；容器余物通过 Forge 的容量与背包校验处理。所有操作均由服务端检查菜单身份、方块有效性和8格距离。

界面相关检查覆盖 signed-short 菜单同步、长整型能量、四种面模式权限、共享输入限额和储能上限；尚未在实际 Minecraft 客户端验证界面渲染与桶交互。

## 1.2.2 应用通量兼容

安装 Applied Flux 后，将通量能量存储元件放入同一 ME 网络的驱动器，以 AE 线缆连接发电机，并将连接面的能量模式设为输出或双向。发电机优先为 AE 网络自身供电，然后将剩余输出直接以 FE 存入通量存储，无需额外通量访问器或能量卡。网络须正常运行，存储元件须有剩余容量且允许写入。普通物品磁盘不能存储 FE。

磁盘按实际接收量扣除发电机储能，使用 long 数量传输，最高档不受单次 int 上限限制。通量磁盘、AE 供电和相邻能量输出共享整机每刻输出预算；磁盘满或拒绝写入时保留未接收的能量。未安装 Applied Flux 时不会加载其类，仍可使用原有 AE 和 FE 功能。输入模式仍沿用 AE 网络供电服务充电，不从通量磁盘取电。
